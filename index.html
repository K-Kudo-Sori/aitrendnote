MCPの大型アップデート（2026-07-28）で何が変わったか —— TypeScript SDK v2で試す

2026年7月28日に公開されたMCP（Model Context Protocol）の仕様アップデートを、TypeScript SDK v2で実際に検証した記事。最大の変更は、initializeハンドシェイクとMcp-Session-Idヘッダーの廃止で、MCPは各リクエストが単体で完結する「1発リクエスト・レスポンス」モデルに変わった。状態が必要な処理はサーバーが返す「ハンドル」をクライアントが引き回す形になり、途中でユーザー入力が必要なケースはrequestStateを持ち回ってリトライするMulti Round-Trip Requestsという新方式に置き換わった。これによりsticky sessionが不要になり水平スケールしやすくなる一方、Roots・Sampling・Loggingはコア機能から非推奨化（12ヶ月の移行期間あり）、認可周りもRFC 9207準拠の強化が入っている。
