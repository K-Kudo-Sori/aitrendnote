OpenAI、意思決定モデル競争が激化する中で Decisions API モデルを全顧客に提供

OpenAI は9月29日の開発者イベントで発表した Decisions API モデルを全顧客に提供開始した。ChatGPT Luna モデルを再構成し、応答時間を1〜3秒から約100〜180ミリ秒に短縮したという。この分野を開拓した TypeSafe の Jev と競合し、2つの公開ベンチマークでは Jev が上位だが、良い意思決定モデルの基準については専門家の間でも意見が分かれている。

Canva、初の画像生成モデル「Canva Craft」を公開

Canva は自社研究チームが開発した初の画像生成モデル「Canva Craft」を公開した。プロンプトから画像を計画してから生成する2段階方式で、最大2K解像度・30種のアスペクト比に対応する。写真ではなく人手でデザインされたテンプレートで学習しており、Dream Lab タブと Canva API から全ユーザーが利用できる。今後、低コスト版の Craftfast / Craft-ultrafast も提供予定。

Claude Duet アプリは Anthropic のエージェントへの賭け

Anthropic は、専門職や小規模事業者向けにタスクの自動化・管理を支援するエージェントアプリ「Claude Duet」を発表した。Claude Opus 5.5 を基盤とし、日次ブリーフィングやダッシュボードの作成、データに基づく提案を行い、専用の仮想マシン上でバックグラウンド実行して必要時に承認を求める。6,000以上のコネクタに対応し、Stripe の Link や Shopify の Shop Pay で購入も可能（承認制）。iOS・Android・Web で Pro/Max 向けに研究プレビュー提供され、利用にはウェイトリスト登録が必要。

1Password、AI エージェントがパスワードを見ずにユーザー代理でログインできる仕組みを開始

1Password は「1Password for Agents」を発表し、AI エージェントが認証情報を見ることなく個人アカウントにログインできるようにした。エージェントは固有のデジタル鍵で本人確認され、ログイン試行ごとにユーザーへ承認通知が届き、認証情報は 1Password 側が入力する。Anthropic、OpenAI、xAI、Meta などのエージェントに対応する。

中国系ハッカーが IT 大手 ConnectWise を侵害し、数千社をスパイ

Microsoft の研究者は、ConnectWise の侵害を中国政府系とみられるハッキンググループによるものと分析した。クラウドバックアップサービスからアプリケーション認証情報を盗み、顧客企業の Microsoft 環境でメールやファイルにアクセスしたという。オープンソースの ARTEX フレームワーク上の AI エージェントを用い、約2,250組織を毎分約3,000回のサインイン試行で標的にした。ConnectWise は同バックアップへのアクセスを停止して調査中。
