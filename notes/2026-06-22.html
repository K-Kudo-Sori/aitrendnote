AIエージェントを「指揮」するOSS「TAKT」とは — 仕組と使い方

TAKT（TAKT Agent Koordination Topology）は、AIエージェントの連携・人間介入タイミング・記録内容を YAML で宣言的に定義するオーケストレーション OSS（MIT ライセンス・TypeScript 製）だ。通常の Claude 単体利用では人間が都度指示・確認する必要があるが、TAKT はワークフロー定義がその進行を代替し、レビューループや暴走検知も構造的に強制できる。設計思想は「AI を信頼するのではなく外から制御する対象として扱う」であり、プロンプトお願いではなく宣言的ワークフローでプロセスを強制する点が特徴だ。ステップ遷移・コンテキスト受け渡し・実行記録がすべて組み込み済みで、自作する場合に必要な多くの実装を省ける。Microsoft Conductor・CrewAI などの競合 OSS も存在するが、TAKT はシンプルな YAML 定義とアクティブなコミュニティが採用の決め手になったと筆者は述べている。

Stop wasting tokens and re explaining your project between sessions

LLM はマークダウンファイル全体を読んでいる。その必要はない。

Apple container で docker compose を動かす

Apple container の永続 Linux VM 機能「container machine」（v1.0 追加）の中で docker engine と docker-compose を完全動作させる手順をまとめた記事だ。machine のデフォルトカーネルには netfilter が含まれておらず、そのままでは docker のネットワーク（-p・bridge・compose）が動かないが、公式 Kata 推奨カーネルに差し替えるだけで解決できる。Ubuntu（systemd）イメージなら `systemctl enable docker` 1 行で自動起動まで完結し、`docker compose` も標準通り動作する。Mac の localhost からコンテナに到達するには macOS のローカルネットワーク権限の都合で root の LaunchDaemon が必要になる。公式に compose サポートが来るまでの現実的な代替手段として、Apple 純正・無料の枠内で docker/compose ワークフローを成立させる方法として紹介されている。
