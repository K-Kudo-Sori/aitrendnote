Claude Code で編集を拒否したファイルが、tee なら4回中4回書けた

Claude Code 2.1.269のchangelogにある「Edit()の拒否ルールがBashのteeコマンドによる書き込みに適用されていなかった」という修正内容を、実際に拒否ルールを設定したファイルへの書き込みを試して検証した記事。旧バージョン2.1.268では、Editツールでの書き換えは拒否される一方、teeコマンドで同じファイルに書き込むよう明示的に依頼すると4回中4回書き込めてしまい、この抜け道を塞いでいたのは権限機構ではなくモデル自身の「遠慮」に過ぎなかったことが判明した。修正後の2.1.270ではteeでの書き込みも機構によって拒否されるようになったが、権限拒否の記録（permission_denials）自体も旧バージョンでは正しく記録されていなかったことも合わせて報告している。
