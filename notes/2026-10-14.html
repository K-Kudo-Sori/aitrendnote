LLM の 23 秒を 0.3 秒にした — decision-only モデル Jev を日本語校正プラグインに実測投入した話

日本語校正プラグインmeisekiに、判断特化モデルJevを組み込んで速度と精度を実測した記事。文脈判断20問をLLM（claude -p）は中央値23.5秒かけたのに対し、Jevは約300msで返し、約77倍高速だった。一致率はJevが17/20、LLMが19〜20/20とやや劣る。Jevを有効にすると判定対象のテキストがTypeSafeのサーバーに送信されるため、機密文書では.meiseki-no-jevファイルで送信を止められる点に注意が必要だと述べている。

Shift-JIS のファイルを Claude Code で1か所直したら、日本語が全部壊れて戻せなくなった

Claude Code 2.1.295までは、Shift-JISなど非UTF-8ファイルをEditで編集するとASCII以外の文字がすべて置換される不具合があり、2.1.296で修正された。著者は40回の測定を行い、旧版ではHaiku 5.5が3/3、Opus 5.5が2/3で日本語が全部壊れ、しかも返事は「変更しました」だった。2.1.296ではいずれも壊れず、Editが拒否されるか使わずに止まった。Windows 10上の261バイトのJavaファイルで検証している。
