スキルの名前を verify にするだけで、Claude Code はコミット前にそれを実行する

Claude Code 2.1.286 の changelog にある、verify という名前のスキルをコミット直前に実行するという挙動を、30回の測定で検証した記事です。コード変更では verify で3/3回実行されましたが、verify2 に変えると0/3でした。2.1.285 や、ドキュメントのみ・テストのみの変更でも実行されませんでした。ディレクトリ名と name: のどちらが引き金かは未分離で、混在変更やユーザースキルは未検証です。重い検査を入れている場合は名前に注意すべきとしています。

RIP, vector database

turbopuffer が、ベクトル検索用DBとして始まったストレージ設計を見直す v3 を発表しました。これまではANNベクトル索引が主索引で、GROUP BY や集計などのクエリプランが制約されていました。v3 では新しい主索引を導入し、ANN を二次索引のひとつとして扱います。これにより全文・正規表現・ベクトル検索の高速化に加え、より多くのSQLクエリを高速に処理できる土台を作るとしています。
