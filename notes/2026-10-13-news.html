Meta、初のフロンティアモデル「Muse Wonder」を公開

Meta Superintelligence Lab は 10月12日、同社初のフロンティアモデル Muse Wonder と Muse Wonder Full を公開した。Meta の社内テストでは Fable 5.1 や GPT-6 Astra に匹敵するスコアで、複雑なコーディングタスクでも優れるとしている。Muse Wonder は Meta Model API で入力100万トークンあたり4ドル、出力20ドルで提供され、Wonder Full は Muse Code 契約者向けに限定される。

Microsoft の Nadella 氏、AI モデルに「緊急ブレーキ」が必要と発言

Microsoft CEO の Satya Nadella 氏は X への投稿で、AI の「信頼アーキテクチャ」を見直すため立ち止まるべきだと述べた。モデルとそれを動かすハーネスの分離、重要な動作の記録、権限者がタスク途中でモデルを停止できる仕組みを提案している。AI 企業がモデルの制御を失ったとの報道を受けた発言とされる。

Microsoft 社長「AI 規制の主導に最適なのは英国」

Microsoft 社長の Brad Smith 氏は BBC のポッドキャストで、身近な製品より AI 企業への監督が緩いと指摘し、早急な規制を訴えた。デプロイ前にモデルをテストする英国 AI Security Institute を根拠に、英国が世界の安全ルール作りに適していると述べた。ホワイトハウスの自主的コミットメントは「良い一歩」だが不十分とし、侵害通知義務や事前の外部評価、キルスイッチを支持した。

元 Plaud 幹部の新会社 Ambi、常時待機型 AI アプリで2600万ドルを調達

元 Plaud 幹部の Peter Mo 氏が共同創業した Ambi が、Luminous Ventures 主導で計2600万ドルを調達した。iPhone・Mac・Apple Watch 向けアプリは会議の議事録に加え、終日の周囲の音声取得にも対応するが、常時取得は初期設定でオフである。今後はデスクトップアプリや画面・カメラ付きハードウェアも計画している。同氏は録音の開示問題について業界として未解決だと認めた。

Blueprints AI、スケッチから許可申請用の建築図面を数分で生成

米サンタモニカのスタートアップ Blueprints AI は、スケッチや PDF から建築基準に適合した許可申請用の図面を数分で生成するソフトを開発した。設計施工会社の8年分の承認済み図面で学習させている。第2世代版は構造・機械・電気・配管・内装まで網羅し、TechCrunch Disrupt で披露され、一般提供される予定だ。最終的には有資格者が確認・捺印する前提で、料金はサブスクリプション制である。
