Introducing Gemma 4 12B: a unified, encoder-free multimodal model

Google が Gemma 4 12B を発表した。16GB VRAM で動作するラップトップ向けのマルチモーダルモデルで、Gemma 4 26B MoE モデルに匹敵するベンチマーク性能を約半分のメモリフットプリントで実現する。最大の特徴はエンコーダレスアーキテクチャで、視覚入力は単一の行列積＋位置埋め込みモジュールに置き換え、音声入力はエンコーダを完全廃止してトークン空間に直接投影することでレイテンシとメモリを削減した。また Multi-Token Prediction（MTP）ドラフターを搭載し推論レイテンシをさらに低減している。Apache 2.0 ライセンスで Hugging Face・Kaggle・LM Studio・Ollama から即座に利用可能で、Gemma 4 シリーズ全体の累計ダウンロードは1.5億回を突破した。

My Agent Skill for Test-Driven Development

Conventional Commits encourages focus on the wrong things

Conventional Commits はコミットメッセージに `fix:` や `feat:` などのタイプ接頭辞を付けるが、筆者はこれがスコープ（変更対象）よりタイプ（変更種別）を優先する本末転倒な設計だと批判する。コントリビューターやデバッガー・インシデント対応者にとって最重要情報は「どの領域が変わったか（スコープ）」であり、変更種別はコミット説明文から自明なケースがほとんどで冗長だと論じる。Conventional Commits ではスコープがオプション扱いのため、むしろ重要な情報が省略されやすい構造的欠陥があると指摘している。

GitHub Copilotの料金改定で大騒ぎになっているので、トークン削減の最新手法をまとめてみた

2026年6月から GitHub Copilot がトークンベースの AI Credits 従量課金（1 AI Credit ≒ $0.01）に移行し、Claude Sonnet は旧制度比9倍・Claude Opus は27倍の消費量と報告されており、Agent mode 多用者には実質的な大幅値上げとなった。現在注目されるトークン削減手法は2つ。①「Caveman Prompt」でLLMを原始人のように簡潔に話させる手法（検証値14〜45%削減）は長いエージェントセッションに有効で、論文によると大型モデルの精度向上にも寄与する場合がある。②静的なプロンプト（システム指示・ツール定義）をコンテキスト先頭に配置してAnthropicのKVキャッシュ（2回目以降90%割引）を効かせる「プロンプトキャッシング」は入力コスト削減に直結する。インライン補完・Next Edit 提案は引き続き AI Credits を消費しない。

非エンジニアでもAIで小さなシステム修正はできる。Claude Code・Cursor時代の依頼術

Cursor や Claude Code などの AI コーディングエージェントを活用することで、非エンジニア（Biz サイド）も文言修正・ボタン色変更・リンク差し替えといった軽微な修正を自走できるようになってきていると筆者は述べる。AI への依頼は「①対象画面（URL）」「②対象箇所（名称）」「③変更内容（具体的）」「④注意点（既存ロジックを変えない等）」の4要素を明示することが精度向上の鍵で、抽象的な表現では失敗しやすい。実作業の流れは Cursor でプロジェクトを開く→AIチャットで依頼→差分確認→ブラウザで動作確認→エンジニアにレビュー依頼の5ステップで、非エンジニアが本番反映まで単独で行う必要はなく「一次対応の自走」を目標とする考え方だ。

AIエージェントのトークン代を節約するNetflixのエンジニアが作ったツール「Headroom」について調べてみた

Netflix のシニアエンジニアが公開した OSS「Headroom」は、AI エージェントへ送るコンテキストをローカルで圧縮してトークン消費を削減するプロキシ・ライブラリだ。JSON（90.6%削減）・シェル出力（85.5%）・ビルドログ（93.9%）で大きな効果を発揮する一方、ソースコードと grep 結果は精度維持のため意図的に無圧縮にしている。実運用の中央値は4.8%にとどまるが、ヘビーなツール使用セッションでは40〜80%になる。特徴的な機能「CCR（Compress, Cache and Retrieve）」は圧縮前の原文をローカル（Redis/SQLite）に保存し、LLM が詳細を要求した際に MCP ツール経由で取得できる可逆圧縮の仕組みで、単純な要約・切り捨てとの大きな差別化点となっている。
