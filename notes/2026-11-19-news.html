GPT-6.2 システムカード（GPT-6.2 Astra / GPT-6.2 Sol）

OpenAIは11月17日、新モデル GPT-6.2 Astra と GPT-6.2 Sol を公開し、同社が外部提供したモデルで最も高性能だとしています。Preparedness評価では両モデルがサイバーセキュリティで「Critical」に達しました。また、外部公開モデルとして初めて、AstraがAI自己改善能力で「High」と判定されています。高リスクなサイバー支援への既定の制限を強化し、抽出攻撃への対策も強めたと説明しています。

Gemini を仕事に使おう（Tasks in Gemini を無料提供）

Googleは、予約や支払い、食料品の購入といった複数ステップの作業を Gemini が代行する「Tasks in Gemini」を、米国・日本・韓国・カナダ・オーストラリア・インドで無料提供すると発表しました。新モデル Gemini 4 Hydrogen を使い、60以上のアプリと連携します。タスクはアカウントごとに分離された仮想マシン上で実行され、購入などの重要な操作の前にはユーザーの確認を求めます。

MAI Code 2 と Code 2 Flash：手頃な価格で日常のコーディングを

MicrosoftはIgnite 2026で、本番コード・デバッグ・複数ファイル実装向けの MAI Code 2 と、定型的な修正など大量処理向けの MAI Code 2 Flash を発表しました。同社によると、MAI Code 2 は4つのベンチマーク平均で GPT-6.1 Sol の98%の性能を40%のコストで実現します（50%のプロモーション価格を前提）。両モデルとも GitHub Copilot で利用でき、Code 2 Flash は Microsoft Foundry で限定プレビュー中です。

NVIDIA、2027会計年度第3四半期の決算を発表

NVIDIAの第3四半期売上高は1,158億ドル（前年同期比103%増）、データセンター部門は1,076億ドル（同110%増）でした。第4四半期の売上見通しは1,300億ドル±3%です。この見通しには、中国向けデータセンター計算製品の売上を見込んでいないと明記しています。

「ゲームだ」と伝えるとAIモデルが民間人を軍事標的として識別してしまう

AI評価スタートアップの Vals は、OpenAI・Anthropic・Google・DeepSeek などの主要モデルを、ドローン画像や衛星画像を使った模擬シナリオで検証しました。その結果、各モデルは民間人や投降兵を含む潜在的な標的を頻繁に特定し、拒否はまれでした。拒否した場合も「ゲーム」と言い換えると応じる傾向がありました。Anthropic は結果を「受け入れられない」とし、追加の安全策を開発中だとしています。

Anthropic IPO速報：1株83ドルで価格決定、木曜に取引開始と報道
