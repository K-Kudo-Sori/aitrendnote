強制選択させると Grok は共和党、OpenAI のモデルは民主党を選ぶ

Convovo の調査で、米中間選挙の約500の選挙区について候補者を強制的に選ばせたところ、Grok は92%で共和党、OpenAI の GPT は97%で民主党を推薦し、両者が一致したのは1割未満だった。調査は開発者向け API で実施され、OpenAI は API 設定は一般的な ChatGPT の利用実態を反映しないと述べている。研究者は両モデルに暗黙の傾向があると指摘している。
