Write() で拒否しても、Claude Code は12回とも書き込んだ。効いていたのは Edit() だけだった

Claude Code 2.1.275のchangelogにある「/update-configがWrite(path)権限ルールを書いていたが、実際のファイル権限検査はEdit(path)ルールとしか一致しない」というバグ修正について、著者が36回の実験で検証した記事。deny設定にWrite(ファイル)のみを書いた場合、Editツール・Writeツール・Bashリダイレクトの全経路で12回とも書き込みがブロックされずに成功してしまったのに対し、Edit(ファイル)を書けば全経路でブロックできることを確認した。2.1.275で修正されたのは/update-configが提案する拒否ルールの「書き方」のみで、既存のWrite()ルール自体の検査ロジックは修正後も効かないままだったと報告している。著者はgrep -n '"Write('で自分の設定を確認し、見つかった場合はEdit()に書き換えるよう推奨している。

ChatGPT now knows what you do on other websites via ad collector
