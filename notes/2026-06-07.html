Universal Memory Protocol – a shared format for agent memory

Universal Memory Protocol（UMP）は、AIエージェントのメモリをトランスポート非依存の共通フォーマットで扱うためのオープンプロトコルである。MCPがツール連携を、A2AがエージェントのP2P連携を標準化したのと同様に、UMPはエージェント間・セッション間・ベンダー間のメモリ共有を標準化する。ポータブルで署名付きの二時間軸レコードとして設計されており、Claude Code・Codex・Cursor等のMCPクライアントやPostgres・Redis・ベクターDBなど各種データストアから利用できる。TypeScript SDKとMCPサーバーが提供されており、HTTP経由でPython・GoなどからもJSON形式で利用可能である。
