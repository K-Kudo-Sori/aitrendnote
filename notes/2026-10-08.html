Docker Agent

Docker Agent（docker-agent）は、宣言的な YAML 設定だけで AI エージェントを構築・実行・共有できる docker CLI プラグインである。コードなしで、専門化した複数のエージェントがタスクを委譲し合うマルチエージェント構成を作れる。ツールは組み込みのものに加え、ローカル・リモート・Docker ベースの MCP サーバーも利用できる。OpenAI、Anthropic、Gemini、AWS Bedrock、Mistral、xAI、Docker Model Runner など複数のモデルプロバイダに対応し、think や todo などの推論支援ツールも備える。
