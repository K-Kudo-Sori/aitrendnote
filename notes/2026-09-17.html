生成AIが書いたドキュメントを読みたくない

拒否ルールを全部消しても、Claude Code は eval を止めた。守っていたのは別の仕組みだった

Claude Code 2.1.273のchangelogにあった「解析できないBash行（eval、env -C）にも拒否ルールを適用する変更を差し戻した」という記述を検証した記事。拒否ルール（deny設定）の有無に関わらず、eval・env -C・time -pの各コマンドは3バージョンとも同じ理由文言で一貫して止まっており、実際にこれらを止めていたのは拒否ルールではなく、その手前にあるBashの静的解析であることを120回の実験で明らかにした。--dangerously-skip-permissionsを付けるとこの静的解析の関門が消え、evalで包んだコマンドは拒否ファイルへの書き込みに3回中3回成功する一方、直接書き込みは引き続き拒否ルールで止まることも確認している。
