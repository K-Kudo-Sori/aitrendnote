Moonshot AI、1兆パラメータの開源コーディングモデル「Kimi K2.7-Code」をリリース

中国のMoonshot AIは2026年6月12日、1兆パラメータのMixture-of-Expertsアーキテクチャを採用したコーディング特化モデル「Kimi K2.7-Code」をModified MITライセンスでHugging Faceに公開した。前バージョン比で推論トークン消費を30%削減しながら、社内ベンチマーク（Kimi Code Bench v2）で21.8%の性能向上を実現。256Kトークンのコンテキストウィンドウと画像・動画入力に対応するビジョンエンコーダを搭載。ただしベンチマーク数値はすべてMoonshot社内計測値であり、独立した第三者評価は未実施。

DatabricksがマルチAIエージェント統合フレームワーク「Omnigent」をApache 2.0でOSS公開

Databricksは2026年6月13日、Claude Code・Codex・PiなどAIエージェントを横断的に統合・制御するメタハーネス「Omnigent」のα版をApache 2.0ライセンスで公開した。複数エージェント間のテキストストリームやツール呼び出しを統一APIで管理し、コスト予算やアクセス権限のポリシーを適用するガバナンス層として機能する。セッションURLの共有によりチームが同一エージェントをリアルタイムで共同レビューする機能も備え、5,000人規模でコーディングエージェントを運用してきたDatabricks自身の知見が設計に反映されている。

GitHub Copilotが使用量ベース課金に完全移行、「GitHub AIクレジット」制度が6月1日から開始
