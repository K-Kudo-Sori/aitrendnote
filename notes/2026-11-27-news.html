Ant、マルチモーダルモデル Ling-3.2-air を MIT ライセンスで公開

Ant Group はテキスト・画像・動画を扱うマルチモーダルモデル Ling-3.2-air の重みを MIT ライセンスで公開した。ハイブリッド線形アテンションの MoE 構成で、言語部は総パラメータ1240億・トークンあたり有効55億。ツール利用エージェントや業務ワークフロー向けで、AutomationBench-AA のタスク完了率は前世代 Ling-3.0-flash-VL の15.7%から61%に向上したという。SGLang・vLLM 向けのデプロイガイドも付属する。

Messages API を Rust に移行（Anthropic）

Anthropic は Claude への主要な入口である Messages API を Python から Rust へ全面移行した経緯を公開した。Claude エージェントが中核のリクエスト経路を約1週間で書き上げ、本番の Python 実装をオラクルとするシャドーイングで差分を検証し、一致率を99.6%まで高めた。結果としてリクエストあたりの CPU 使用量は約70%、メモリは80%以上削減され、初トークンまでの時間の中央値は約20%短縮された。検証がボトルネックとなり、人間のレビューは依然必要だったとしている。

Nvidia チップの購入者、GPU 購入に際し中国の借り手を排除するよう求められる（関係者）

Nvidia チップの販売側が、計算資源を貸し出す「ネオクラウド」に対し、中国企業へ容量を貸す場合はチップを供給しないと伝えていると CNBC が関係者の話として報じた。背景には、米商務省 BIS が11月19日に施行した、中国企業による先端計算資源への遠隔アクセスを締め付ける暫定最終規則がある。海外データセンター経由で中国企業が最先端チップを借りる抜け道を塞ぐ狙いで、販売側は新たな買い手を探しているという。

米当局、SpaceX の AI データセンター衛星を承認——100万基すべて

米連邦通信委員会（FCC）は、軌道上で AI ワークロードを処理する SpaceX の衛星群「Starmind」を最大100万基まで打ち上げることを承認した。軌道上データセンターの衛星群全体が承認されるのは初めてで、太陽光発電とレーザー通信で接続される計画。2033年11月までに最初の運用衛星、2040年までに全基の配備が条件で、天文学への干渉や軌道の持続可能性を懸念する声も出ている。

OpenAI、Chat と Work の統合に伴いヘビーな ChatGPT ユーザーは上限に早く達する可能性があると説明

OpenAI は ChatGPT の Chat と Work を統合した体験を一部の Pro 契約者向けに展開し始めた。両者は1つの利用枠を共有し、Instant モデルとの会話は枠に数えられず上限到達後も利用できる。同社は大半のユーザーには影響しないが、ごく一部のヘビーユーザーは上限に早く達する可能性があるとし、12月により多くのユーザーへ共有枠を広げる予定。
